# Orizon Tech Engineering Standards

These standards are the reusable engineering baseline for existing and future Orizon Tech projects.

Load only the standards relevant to the current task. Project-local rules can be stricter and take precedence.

## Core delivery order

Database -> Security -> Backend -> Frontend -> Tests -> Observability -> Staging -> Production.
