# Orizon Audit

Apply `orizon-engineering-profile` and `orizon-engineering-handbook`.

Audit only standards relevant to the repository and requested focus.
Check architecture, source-control hygiene, data, auth, secrets, API contracts, frontend/backend parity, mobile, testing, CI/CD, security, observability, backup/recovery and production readiness.
Use evidence from code, configuration, CI and runtime validation where available.
Classify findings as blocker, high, medium or improvement.
Do not invent failures that were not observed.
Finish with an ordered remediation plan and the fastest path to production confidence.
